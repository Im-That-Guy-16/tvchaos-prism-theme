A clean, modern override theme for TVChaosUK — refined colours, typography, spacing and depth on top of the Dark Purple theme.

Stylesheet URL

style.css View stylesheet

How to apply

  • On TVChaosUK, open Settings → General → External CSS Stylesheet.
  • Paste the full URL to style.css into the CSS URL field.
  • Save. To revert, simply clear the field.
